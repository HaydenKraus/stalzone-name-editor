# STALZONE Name Editor

Редактор названий предметов и текстов интерфейса STALZONE. Работает с файлами `.lang` в папке игры: можно менять названия, описания и подписи, не трогая остальные файлы.

## Готовый EXE (Python не нужен)

Скачай **`StalzoneNameEditor.exe`** из [последнего релиза](https://github.com/HaydenKraus/stalzone-name-editor/releases/latest) — это один самостоятельный файл. Python и установка библиотек не требуются.

1. Скопируй `StalzoneNameEditor.exe` в любую **записываемую** папку (например, на рабочий стол или в `C:\STALZONE-LocEditor`).
2. Запусти двойным кликом.
3. Резервные копии и экспорт будут создаваться рядом с exe, в папках `backups` и `exports`.

Если Windows покажет предупреждение SmartScreen, выбери «Подробнее» → «Выполнить в любом случае» только если файл получен из доверенного источника. При сохранении в `Program Files` может понадобиться запуск от имени администратора.

Пересобрать exe из исходников:

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed --name StalzoneNameEditor app.py
```

## Что нужно для запуска из исходников

1. **Windows 10 или 11.**
2. **Python 3.10 или новее** — официальный установщик с [python.org](https://www.python.org/downloads/). При установке включи галочку **«Add python.exe to PATH»**. Tkinter входит в стандартную установку Python для Windows, отдельно ставить ничего не нужно.
3. **Установленная STALZONE.**
4. **Права на запись в папку игры.** Если игра лежит в `C:\Program Files (x86)\...`, может понадобиться запуск от имени администратора.
5. Вся папка программы целиком: `app.py`, `categories.py`, `detect.py`, `langfile.py`, `start.bat`. Без этих файлов программа не запустится. `pip` и сторонние библиотеки не нужны.

## Запуск из исходников

- Двойной клик по **`start.bat`**.
- Или вручную: открыть терминал в папке программы и выполнить:
  ```powershell
  python app.py
  ```

Если Python не найден, `start.bat` покажет сообщение. Установи Python и попробуй снова.

## Первый запуск

Программа сама ищет игру в библиотеках Steam, реестре и типовых папках.

Если игра не нашлась:

1. Нажми **«Обзор…»**.
2. Выбери папку, в которой лежат `modassets` и `bin_ru` (обычно `...\Steam\steamapps\common\STALZONE`).
3. Нажми **«Найти»**.

В выпадающем списке появятся найденные файлы локализации. Для названий предметов и мира выбери:

- **«Предметы и мир · ru»** — `modassets/assets/stalker/lang/ru.lang`.

Для интерфейса:

- **«Интерфейс · ru»** — `modassets/assets/gloomycore/lang/ru.lang`.

Также могут быть файлы других языков и юрисдикции Korea.

## Как менять названия

1. Выбери файл локализации.
2. Слева выбери категорию: «Оружие», «Броня», «Гранаты и взрывчатка» и т. д.
3. Найди строку через список или кнопку **«Поиск предметов»**.
4. Выдели строку, измени поле **«Станет»**.
5. Нажми **«Применить»** — изменение пока только в памяти.
6. Нажми **«Сохранить файл»** — только теперь файл на диске изменится.

Важно: **закрой игру перед сохранением**. Иначе файл может быть занят или игра перезапишет его при выходе.

Галочка **«Только названия (без описаний)»** включена по умолчанию. Сними её, если нужно менять описания предметов.

## Горячие клавиши

В полях ввода:

- `Ctrl+A` — выделить всё
- `Ctrl+C` / `Ctrl+X` / `Ctrl+V` — копировать / вырезать / вставить
- `Ctrl+Z` / `Ctrl+Y` — отменить / повторить

В программе:

- `Ctrl+S` — сохранить файл
- `Ctrl+F` — перейти к поиску
- `Enter` в поле названия — применить
- `Esc` в поле названия — вернуть исходное значение

## Копии и восстановление

Вкладка **«Файлы и копии»**.

- При каждом сохранении старая версия файла автоматически попадает в папку `backups` рядом с программой.
- **«Создать копию…»** открывает диалог сохранения: можно выбрать любую папку и изменить имя файла. Последняя выбранная папка запоминается до закрытия программы.
- **«Переименовать»** меняет имя выбранной копии из списка `backups`.
- **«Восстановить выбранную»** заменяет текущий файл копией. Перед этим текущая версия тоже сохраняется в `backups`.
- **«Из файла…»** позволяет восстановить копию, которая лежит вне папки `backups`.

## Экспорт и импорт

На вкладке **«Файлы и копии»**:

- **«Экспорт в JSON…»** — сохраняет пары «ключ → значение». Можно включить только названия без описаний.
- **«Импорт из JSON…»** — применяет значения к совпадающим ключам в памяти. После импорта обязательно нажми **«Сохранить файл»** на вкладке «Редактор».

Импорт не добавляет новые ключи: он меняет только те, которые уже есть в выбранном файле локализации.

## Если что-то не работает

**«python не является внутренней или внешней командой»**  
Python не установлен или не добавлен в PATH. Переустанови его с галочкой «Add python.exe to PATH» или запускай через `py app.py`.

**«Permission denied» / «Отказано в доступе» при сохранении**  
Закрой игру. Если не помогло — запусти `start.bat` от имени администратора (правый клик → «Запуск от имени администратора»).

**Игра не находится автоматически**  
Нажми «Обзор…» и укажи папку, где находятся `modassets` и `bin_ru`.

**Названия не изменились в игре**  
Проверь, что нажал именно «Сохранить файл», и перезапусти игру. Для названий предметов нужен файл `stalker`, для интерфейса — `gloomycore`.

**После обновления игры названия сбросились**  
Это нормально: игра заново скачивает файлы локализации. Верни свои значения из JSON-экспорта или из копии.

**Программа не запускается**  
Проверь, что скопирована вся папка, а не только `app.py`. Запусти из терминала, чтобы увидеть текст ошибки:
```powershell
python app.py
```

## Что редактировать можно

Программа предназначена только для файлов локализации `.lang`: названия предметов, описания, подписи интерфейса. Не используй её для изменения других файлов игры.

По правилам EXBO изменение названий предметов и перевод интерфейса относятся к разрешённым изменениям, но правила могут обновляться. Перед распространением своих изменений сверяйся с официальным списком допустимых изменений EXBO.
